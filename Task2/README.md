# Таблица переходов платежа

Состояние показывает результат платежа; активный элемент BPMN — текущий шаг процесса. Доставка уведомления не меняет финансовый результат.

## Основная Saga

| Исходное состояние | Переходное состояние | Событие |
| --- | --- | --- |
| Платёж отсутствует | CREATED | CREATE_PAYMENT: входные данные приняты, платёж зарегистрирован |
| CREATED | DEBITED | DEBIT_FUNDS: списание подтверждено |
| CREATED | REJECTED | Получен подтверждённый отказ списания либо отмена до списания; возврат не требуется |
| DEBITED | CHECK_PENDING | Запущены проверки |
| CHECK_PENDING | APPROVED | Окончательное ALLOW записано через RECORD_DECISION |
| CHECK_PENDING | BLOCKED | Окончательное DENY записано через RECORD_DECISION |
| CHECK_PENDING | MANUAL_REVIEW | FraudCheck вернул MANUAL, началось ожидание оператора |
| CHECK_PENDING | APPROVED | Истёк cut-off первоначальной проверки без окончательного решения; источник решения — cutoff |
| MANUAL_REVIEW | APPROVED | Оператор разрешил операцию до завершения ожидания |
| MANUAL_REVIEW | BLOCKED | Оператор запретил операцию до завершения ожидания |
| MANUAL_REVIEW | APPROVED | Истекли 20 минут; ручная задача прервана, записано разрешение по cut-off |
| APPROVED | SUCCEEDED | TRANSFER_FUNDS подтвердил перевод; pivot пройден |
| APPROVED | REFUND_PENDING | Перевод достоверно не выполнен и получен окончательный отказ |
| BLOCKED | REFUND_PENDING | Начата компенсация списания |
| DEBITED / CHECK_PENDING / MANUAL_REVIEW / APPROVED | REFUND_PENDING | Принята отмена клиента или окончательный отказ другой проверки до начала перевода; ожидания закрыты |
| REFUND_PENDING | REFUNDED | REFUND_FUNDS завершён, результат подтверждён через FINISH_REFUND |
| REFUND_PENDING | REFUND_PENDING | Временная ошибка возврата; ожидается повтор с тем же ключом |
| SUCCEEDED | SUCCEEDED | Уведомление клиенту отправлено либо ожидает повторной отправки |
| REFUNDED | REFUNDED | Уведомления отправлены либо ожидают повторной отправки |

В прототипе первоначальный cut-off настроен на 30 секунд, ручная проверка — на 1200 секунд.

## Ошибки, повторы и конкуренция

| Исходное состояние | Переходное состояние | Событие |
| --- | --- | --- |
| Любое нетерминальное | То же состояние | Повторная доставка уже выполненного шага: в целевой системе возвращается сохранённый результат без повторного финансового эффекта |
| Любое нетерминальное | То же состояние | Временная техническая ошибка до финансового эффекта; повтор с задержкой |
| CREATED / APPROVED / REFUND_PENDING | RESOLUTION_PENDING | Запрос списания, перевода или возврата отправлен, но его результат неизвестен |
| RESOLUTION_PENDING | DEBITED / SUCCEEDED / REFUNDED | Сверка подтвердила соответствующую денежную операцию |
| RESOLUTION_PENDING | CREATED / APPROVED / REFUND_PENDING | Сверка подтвердила отсутствие эффекта; допустим повтор исходной операции с прежним ключом |
| RESOLUTION_PENDING | REJECTED / REFUND_PENDING | Сверка подтвердила окончательный отказ списания / перевода |
| CHECK_PENDING / MANUAL_REVIEW | APPROVED либо BLOCKED | Конкуренция ответа и таймера: движок обрабатывает один исход текущего ожидания, оставшаяся ветка прекращается |
| APPROVED | APPROVED | Повтор ALLOW или повторный cut-off не создаёт новую попытку перевода с новым ключом |
| APPROVED | APPROVED | DENY из проверки, завершённой по cut-off, игнорируется даже до отправки перевода |
| SUCCEEDED | SUCCEEDED | Поздний DENY из завершённой проверки игнорируется; новый запрос клиента или обнаружение мошенничества запускает отдельный возврат без изменения исходной Saga |
| REFUNDED / REJECTED | То же состояние | Поздний ответ, дубль решения или повтор отмены не переоткрывает платёж |

RESOLUTION_PENDING хранит исходное состояние, тип и ключ операции. Следующее состояние зависит от результата её сверки.

Если таймер сработал первым, позднее решение оператора отклоняется. После перезапуска движка исходный 20-минутный срок сохраняется.

## Отдельный возврат после pivot

| Исходное состояние возврата | Переходное состояние | Событие |
| --- | --- | --- |
| Возврат отсутствует | REFUND_REQUESTED | CREATE_REFUND: принят запрос клиента или fraud-постфактум |
| REFUND_REQUESTED | REFUND_PROCESSING | Подтверждены основание, исходный платёж и допустимая сумма |
| REFUND_REQUESTED | REFUND_REJECTED | Основание недействительно или сумма превышает остаток доступного возврата |
| REFUND_PROCESSING | REFUND_COMPLETED | REFUND_SETTLED_PAYMENT подтверждён |
| REFUND_PROCESSING | REFUND_PROCESSING | Временная ошибка, ожидается автоматический повтор |
| REFUND_PROCESSING | REFUND_RESOLUTION_PENDING | Результат запроса неизвестен, выполняется сверка |
| REFUND_RESOLUTION_PENDING | REFUND_COMPLETED / REFUND_PROCESSING | Сверка подтвердила исполнение / отсутствие эффекта |
| REFUND_COMPLETED | REFUND_COMPLETED | Повтор запроса возвращает существующий результат |

Исходный платёж остаётся SUCCEEDED, а возврат связывается с ним по идентификатору. Бизнес-отказ завершает попытки; техническая ошибка не означает REFUND_COMPLETED.
